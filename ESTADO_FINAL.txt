📞 SOLUCIÓN DE PROBLEMAS:

Si mvn no funciona:
   → Instala Maven desde: https://maven.apache.org/download.cgi
   → Añade a PATH: C:\Users\USERNAME\apache-maven\bin

Si Java no se encuentra:
   → java -version (verifica que esté en PATH)
   → Instala JDK 25 desde https://www.oracle.com/java/

Si Maven compila pero falla:
   → Ejecuta: mvn clean (limpia compilaciones)
   → Intenta de nuevo: mvn package -DskipTests
