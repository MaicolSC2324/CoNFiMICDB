PARÁMETROS ORIGINALES vs NUEVOS:
═════════════════════════════════════════════════════════════════════════════════

❌ ORIGINAL:
   spring.datasource.url=jdbc:mysql://localhost:3306/confi_db?useSSL=false

✅ ACTUALIZADO:
   spring.datasource.url=jdbc:mysql://localhost:3306/confi_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC&createDatabaseIfNotExist=true


PARÁMETROS AGREGADOS Y SU FUNCIÓN:
═════════════════════════════════════════════════════════════════════════════════

1. allowPublicKeyRetrieval=true
   ├─ Propósito: Permite la autenticación con MySQL 8.0+
   ├─ Problema que resuelve: Error "Public Key Retrieval is not allowed"
   └─ Efecto: El driver puede recuperar la clave pública del servidor

2. serverTimezone=UTC
   ├─ Propósito: Define la zona horaria estándar
   ├─ Problema que resuelve: Errores de conversión de fechas/horas
   └─ Efecto: Todas las operaciones con fechas usan UTC

3. createDatabaseIfNotExist=true (NUEVO - Solución a tu pregunta)
   ├─ Propósito: AUTO-CREAR la base de datos si no existe
   ├─ Problema que resuelve: No es necesario crear manualmente la BD
   └─ Efecto: Cuando ejecutas la app, crea "confi_db" automáticamente
   └─ Importante: Requiere que MySQL esté corriendo


CÓMO FUNCIONA LA AUTO-CREACIÓN DE BASE DE DATOS:
═════════════════════════════════════════════════════════════════════════════════

Flujo cuando ejecutas el proyecto:
──────────────────────────────────
1. Aplicación intenta conectarse a: jdbc:mysql://localhost:3306/confi_db
2. Si la BD "confi_db" NO existe:
   └─ MySQL crea automáticamente la base de datos
3. Si la BD ya existe:
   └─ Se conecta normalmente
4. Después de conexión:
   └─ Hibernate crea las tablas automáticamente (ddl-auto=update)

Requisitos para que funcione:
────────────────────────────
✓ MySQL DEBE estar corriendo
✓ El usuario (root) debe tener permisos de CREATE DATABASE
✓ La contraseña debe ser correcta (123456789)


PARÁMETRO createDatabaseIfNotExist=true:
═════════════════════════════════════════════════════════════════════════════════

Qué hace:
   • Si BD no existe → Crea "confi_db" automáticamente
   • Si BD existe → Usa la existente
   • Crea las tablas automáticamente después

Ventajas:
   ✓ No necesitas crear la BD manualmente
   ✓ El proyecto es más portable
   ✓ Usuarios pueden ejecutar sin pasos previos

Desventajas:
   • Requiere que MySQL esté CORRIENDO siempre
   • No funciona si MySQL está apagado


PARÁMETRO ddl-auto=update:
═════════════════════════════════════════════════════════════════════════════════

Qué hace:
   • Crea tablas que no existen
   • Agrega columnas nuevas si se modifican las entidades
   • NO borra columnas ni tablas

Valores posibles:
   • update (ACTUAL) → Crea/actualiza pero no borra
   • create-drop → Crea al iniciar, borra al cerrar (solo desarrollo)
   • create → Crea siempre (borra datos previos)
   • validate → Solo valida (no hace cambios)


RESUMEN FINAL:
═════════════════════════════════════════════════════════════════════════════════

Tu application.properties ahora:

1. Conecta a MySQL con autenticación segura (allowPublicKeyRetrieval=true)
2. Define zona horaria estándar (serverTimezone=UTC)
3. AUTO-CREA la base de datos si no existe (createDatabaseIfNotExist=true)
4. AUTO-CREA las tablas cuando inicia (ddl-auto=update)

Resultado:
   ✅ Puedes ejecutar el proyecto sin pasos previos
   ✅ Si MySQL está corriendo, todo se crea automáticamente
   ✅ Error de "Public Key Retrieval" está solucionado


INSTRUCCIONES PARA CREAR INSTALABLE:
═════════════════════════════════════════════════════════════════════════════════

Con estos cambios, para crear el instalable sigue:

1. Asegúrate que MySQL esté corriendo
2. Compila el proyecto:
   mvn clean package -DskipTests

3. Crea el .exe con Launch4J:
   - Abre launch4j.exe
   - File → Open → ConFiMICDB.xml
   - Click Build

4. Copia para distribución:
   - ConFiMICDB-v1.0.exe
   - application.properties (con usuario/contraseña del usuario)
   - instalar.bat
   - verificar_requisitos.bat

5. Los usuarios ejecutan:
   - Inician MySQL
   - Ejecutan instalar.bat
   - Editan application.properties (usuario/contraseña)
   - ¡Listo!
